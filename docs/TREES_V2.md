# Деревья v2: архитектура

## Блоки
- **Ветвь** (на породу): радиус 1..7 пикселей, 6 булевых связей (up/down/north/south/east/west), мультипарт-модель
  (центральный куб + рукава). Радиус 8 это обычное бревно.
- **Бревно** (на породу): полный блок с осью, кора 32x32.
- **Листва** (на породу): блок со случайным распадом, `distance` и `persistent`, 3 варианта модели.
- Все в тегах `minecraft:logs` / `leaves` / `mineable/axe`, дроп: брёвна и палки, листва: саженцы и палки как у ванильной.

## Генератор (чистая Java, без Minecraft)
1. Скелет: ствол + ветви к облаку точек кроны (space colonization).
2. Радиусы: pipe model, n = 2.5, листья на концах дают минимальный радиус.
3. Растеризация: по отрезкам, радиус округляется до класса 1..8.
4. Связи ветвей вычисляются по соседям.
5. Листва: площадки у концов ветвей, BFS-расстояния до ветви.

## Ресурсы
Скрипты на Python создают текстуры, модели, blockstate, items, loot tables, теги и lang. Рендерер проверяет вид.

## Риски
- Код с Minecraft не компилируется в песочнице, проверка только в вашей сборке Actions.
- Подключение к биомам откладывается до проверки `/place feature`.

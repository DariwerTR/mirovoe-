# Исследование: как делают реалистичные деревья

Что изучено и что из этого берём в Wildlands. Только то, что подтверждено источниками.

## 1. Моды Minecraft

**Dynamic Trees.** Ветви и листва живут по разным правилам: сеть ветвей считается как граф с толщиной,
листва как клеточный автомат (клетка живёт, пока рядом есть ветвь или соседняя листва).
Модели ветвей запекаются (BakedModel), у каждого вида свой алгоритм роста, деревья конкурируют за свет.
Вывод: толщина ветви по радиусу и отдельная логика листвы дают узнаваемое дерево.

**Treealism.** Не меняет ветвление, а увеличивает размеры и разнообразие: крупные старые деревья
доминируют, подлесок плотный. Вывод: разброс по высоте и возрасту так же важен, как форма.

**Better Leaves (ресурспаки).** Объёмная листва делается моделью из пересекающихся плоскостей
с прозрачными краями текстуры. Вывод: листву делаем отдельной моделью с вариантами.

## 2. Наука о форме дерева

- **Pipe model / правило Леонардо:** сечение ствола равно сумме сечений ветвей, r^n = r1^n + r2^n,
  n у реальных деревьев 1.5-3, у древесных пород около 2-2.5. Мы берём n = 2.5.
  Без правильного утончения дерево не читается как дерево.
- **Space colonization (Runions 2007):** ветви растут к точкам в объёме кроны, поэтому крона
  получается естественной, а не набором шаров.
- **Weber & Penn (1995):** вид задаётся несколькими параметрами: форма кроны (коническая,
  сферическая, пламя), доля голого ствола, число ветвей по уровням, углы, сбег.

## 3. Что берём

1. Скелет дерева: граф узлов, радиус считается снизу вверх по pipe model (n = 2.5).
2. Крона: ветви растут к облаку точек формы, свойственной виду.
3. Растеризация по классам радиуса: тонкие ветви это блоки-ветви (1-7 пикселей), толстый ствол это полные блоки.
4. Листва: отдельные блоки с моделями-вариантами и распадом по расстоянию.
5. Текстуры 32x32, процедурные (кора с трещинами, листья с прозрачными краями).
6. Проверка: собственный рендерер, чтобы смотреть результат без игры.
